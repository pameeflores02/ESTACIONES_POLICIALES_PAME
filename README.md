# 🚓Estaciones Policiales más Cercanas — La Ceiba

Proyecto de Computación en la Nube.

Aplicación web que recibe coordenadas (latitud y longitud) y muestra
las 3 estaciones policiales más cercanas de La Ceiba, Honduras,
usando la fórmula de Haversine.

## 🛠️ Tecnologías
- Python + Streamlit (servicio y página web)
- GitHub (código fuente)
- Streamlit Community Cloud (despliegue)
- Google Colab + ngrok (pruebas)

## ▶️ Ejecutar localmente
pip install -r requirements.txt
streamlit run app.py
